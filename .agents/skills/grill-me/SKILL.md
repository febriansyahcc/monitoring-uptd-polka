# Grill Me - Interactive Alignment Skill

## Objective
Conduct a structured, step-by-step interview with the user to resolve ambiguities, technical choices, and design preferences before starting major implementation work.

## Execution Pattern
1. Ask clear, focused questions about design, data models, or UX preferences.
2. Provide concrete options with trade-offs.
3. Incorporate user responses into the implementation plan.
