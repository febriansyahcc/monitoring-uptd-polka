# 7. Monitoring Operasi Engine

Logsheet Control Panel dan Engine Area untuk CAT #4 dan ABC #6. <span class="manual-badge">Akses: Lihat Monitoring Operasi Engine</span>

## Filter & tampilan

- **Tanggal**: pilih tanggal logsheet.
- **Jenis engine**: **CAT #4** atau **ABC #6**. Setiap jenis memiliki parameter logsheet sendiri.
- Tab **Control panel**: pembacaan panel kontrol generator per jam (tegangan, arus, daya, frekuensi, dsb.).
- Tab **Engine area**: pemeriksaan kondisi mesin per jam (tekanan, temperatur, level, dsb.).

## Menambah logsheet <span class="manual-badge">Perlu izin: Input/Edit Monitoring Operasi Engine</span>

1. Pilih **tanggal**, **jenis engine**, lalu tab **Control panel** atau **Engine area**.
2. Tekan **Tambah Data ...** di atas tabel.
3. Pilih **jam** pembacaan dan (untuk CAT #4) **engine** yang diperiksa.
4. Isi setiap parameter sesuai penunjukan alat. Parameter pilihan (mis. kondisi Normal / Tidak Normal) diisi dengan memilih salah satu opsi.
5. Tekan simpan. Data tampil di tabel menurut jam dan engine.
