# 3. Peran & Hak Akses

Apa yang dapat dilakukan setiap peran pengguna. <span class="manual-badge is-public">Akses: Semua Pengguna</span>

Setiap akun memiliki satu **peran** dan sekumpulan **izin**. Menu yang tidak diizinkan tidak akan tampil, dan tombol tambah / edit / hapus hanya muncul bila Anda memiliki izin input. Hak akses bawaan per peran:

| Modul | Admin | Manager | TL Operasi | TL Pemeliharaan | Operator |
| --- | --- | --- | --- | --- | --- |
| Dashboard | Lihat | Lihat | Lihat | Lihat | Lihat |
| Monitoring Arus | Lihat + Input | Lihat | Lihat + Input | Lihat | Lihat + Input |
| kWh Produksi | Lihat + Input | Lihat | Lihat + Input | — | Lihat + Input |
| Operasi Engine | Lihat + Input | Lihat | Lihat + Input | Lihat | Lihat + Input |
| Gangguan | Lihat + Kelola | Lihat | — | Lihat + Kelola | Lihat + Kelola |
| Stok BBM | Lihat + Input | Lihat | Lihat | — | Lihat + Input |
| Pengguna | Kelola | — | — | — | — |

::: info Catatan
Tabel di atas adalah pengaturan awal. Administrator dapat menambah atau mengurangi izin setiap akun, sehingga akses Anda bisa berbeda.
:::
