# 2. Masuk, Keluar & Profil

Cara login, lupa password, mengubah profil, dan logout. <span class="manual-badge is-public">Akses: Semua Pengguna</span>

## Masuk ke aplikasi

1. Buka alamat aplikasi di browser (Chrome, Edge, atau Firefox versi terbaru).
2. Isi **Email atau NIP** dan **Password** akun Anda.
3. Tekan **Masuk**. Anda akan diarahkan ke Dashboard.

<figure class="manual-figure">

![Halaman login.](/images/manual/login.png)

<figcaption>Halaman login.</figcaption>
</figure>

::: warning Perhatian
Akun yang dinonaktifkan Administrator tidak dapat login (muncul pesan "Akun Anda sedang nonaktif"). Jika password selalu ditolak, hubungi Administrator.
:::

**Lupa password:** tekan tautan **Lupa password?** di halaman login. Aplikasi tidak mengirim email reset; hubungi Administrator untuk mengatur ulang password Anda.

## Mengubah nama atau password

1. Tekan nama Anda di pojok kanan atas (di ponsel: ikon orang).
2. Pada kartu **Data akun**, ubah **Nama** lalu tekan **Simpan profil**.
3. Pada kartu **Ganti password**, isi password saat ini, password baru (minimal 8 karakter, harus berbeda), dan konfirmasinya, lalu tekan simpan.

<figure class="manual-figure">

![Halaman Profil Saya: ubah nama dan ganti password.](/images/manual/profil.png)

<figcaption>Halaman Profil Saya: ubah nama dan ganti password.</figcaption>
</figure>

::: info Catatan
Email, NIP, dan peran (role) hanya dapat diubah oleh Administrator.
:::

## Elemen di bagian atas layar (header)

- **Judul halaman** yang sedang dibuka.
- **Tanggal, jam WIT, dan shift berjalan**: acuan waktu pengisian data.
- **Ikon bulan / matahari**: beralih mode gelap / terang (tersimpan di perangkat).
- **Ikon ?**: membuka panduan untuk halaman yang sedang dibuka.
- **Ikon keluar**: logout. Selalu logout jika memakai komputer bersama.
